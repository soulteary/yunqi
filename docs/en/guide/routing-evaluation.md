# Paired routing evaluation

Use `go run ./cmd/routing-eval --input paired.json --check` from `backend-go/` to replay a fixed, paired measurement dataset. The evaluator makes no upstream calls, changes no routing policy and never substitutes HTTP success for semantic quality. `eligible_for_manual_review` requires human review; it is not automatic rollout.

The version-1 JSON schema contains immutable `baselineVersion`, `candidateVersion`, `graderVersion`, a SHA-256 `fixtureSha256` for the controlled prompts/tools/settings, `evidenceSource` (`offline_paired` or `shadow_paired`), `gates`, and `cases`. Each case has a unique `id`, a `stratum`, and baseline/candidate measurements: independently graded `quality` (0–1 or null), actual all-attempt `costUsd` (null when incomplete), and required `latencyMs`, `retries`, `success`. Include failures and pair the same case; unrelated production windows are not paired evidence. Prompts, outputs, credentials and unknown fields are rejected. The importer attests measurement authenticity; the evaluator validates structure and calculations, not external graders or invoices.

Limits: 10,000 pairs, 64 strata, 4 MiB. Defaults: minimum 30 pairs per stratum, no quality loss, cost ratio at most 1, P95 ratio at most 1.1, no retry or success-rate regression. Every stratum must pass, preventing aggregate gains hiding subgroup loss. Missing quality/cost or inconclusive non-inferiority yields `insufficient_evidence`; observed regressions yield `rejected`. P95 uses nearest rank including failures. Quality uses paired mean delta minus 2.045 standard errors: a descriptive approximation, not causal proof or a multiple-testing guarantee. `--check` exits nonzero for either insufficient or rejected evidence.

Global administrators can persist evidence and reports with `POST /api/autopilot/evaluations`, list the latest 100 via GET, and export a run using `GET /api/autopilot/evaluations/:id/dataset`. Scoped administrators and limited roles are denied. Records survive restart in `autopilot.db`; export regularly for longer retention. Missing persistence returns 503. Canonical case ordering yields a reproducible content ID independent of upload order. No sampling, affinity, quota, budget or live policy is mutated.
