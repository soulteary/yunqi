# 隐私政策

Yunqi 是一个自托管的 AI API 代理与协议转换网关。Yunqi 项目本身不包含遥测、广告追踪或用户行为分析功能。

## 项目维护者不会收集的数据

Yunqi 项目维护者不会从用户自托管的 Yunqi 实例收集以下数据：

- API 请求内容或响应内容
- API Key、访问密钥或上游服务凭据
- 渠道配置、模型配置或代理配置
- 用户、设备或使用统计数据
- 浏览器控制台的本地偏好与认证状态

## 代理请求如何处理

Yunqi 作为代理网关运行时，会在用户自己的部署环境中处理 API 请求，并根据用户配置转发给对应的上游模型服务商。

这意味着：

- 请求数据会经过用户自己运行的 Yunqi 服务
- 请求数据会被转发给用户配置的上游 API 服务商
- 上游 API 服务商可能会根据各自的服务条款和隐私政策处理这些数据

请在使用前确认你所配置上游服务商的隐私政策和数据处理规则。

## 日志和本地数据

Yunqi 的日志由部署者控制。根据部署方式和配置不同，以下信息可能保存在用户自己的环境中：

- Yunqi 服务日志
- 访问日志和错误日志
- 反向代理、容器平台或系统服务日志
- 浏览器控制台的本地偏好与认证状态

这些数据不会上传给 Yunqi 项目维护者。部署者应自行管理日志保留、访问权限和密钥保护策略。


## 文档站和下载

访问 Yunqi 文档站、GitHub 仓库或 GitHub Releases 时，托管平台可能会产生基础访问日志。这些日志由对应平台处理，不由 Yunqi 自托管实例生成。


## 联系方式

如发现隐私相关问题，请通过 GitHub Issues 或安全披露渠道联系项目维护者。

## Browser console / 浏览器控制台

管理凭据与偏好按现有认证机制保存在浏览器本地存储中。版本检查会访问 GitHub Releases；客户端配置生成在浏览器内完成，导出的运行诊断使用字段白名单，不包含访问密钥、上游凭据或请求正文。发布产物提供 SHA256 校验文件。
